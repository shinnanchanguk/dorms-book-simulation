# 이 책의 모양 지키기

선생님 칸 화면이 시뮬레이션 교육 책의 다른 칸(교육과정 · 생각 나누기 · 기여도)과 같은 책으로 보이게 하는 규칙입니다.
시뮬레이션 교육 책은 첫 칸의 작업실처럼 **도면 느낌**이에요: 어두운 바탕, 은빛 글자, 하늘빛 강조, 모서리 꺾쇠, 옅은 모눈, 고정폭 숫자.
구조를 바꿔도 아래만 지키면 같은 책처럼 보여요. 모양 자체를 바꾸고 싶으면 바꿔도 됩니다. 다만 맨 아래 '바닥 규칙'은 지켜 주세요.

실제 값은 `dist/style.css` 에 있고, 새 화면에 옮겨 쓰기 쉬운 최소 묶음은 `design/book-look.css` 에 있어요.

## 색

- 바탕 · 글자 · 선은 도름스가 건네는 책 색을 씁니다. 화면 맨 위에서 `dorms.applyTheme(theme)` 를 부르면 아래 이름으로 들어와요.
  - `--paper` 종이(바탕) · `--ink` 글자 · `--ink-light` 흐린 글자 · `--border-light` 얇은 선 · `--border-dark` 진한 선
- 도름스가 색을 주지 않을 때만 이 책의 기본 색을 씁니다.

| 자리 | 기본 색 |
|---|---|
| 바탕(`--sm-paper`) | #0C1118 |
| 글자(`--sm-ink`) | #E2E8F0 |
| 흐린 글자(`--sm-muted`) | #AEB9C7 |
| 얇은 선(`--sm-line`) | #45505E |
| 진한 선(`--sm-edge`) | #5B6879 |
| 강조(`--sm-accent`) | #A7DAED |

- 강조색은 `StudioPalette.apply(theme)`(`dist/palette.js`)가 종이색에 맞춰 넣어요. 어두운 종이에서는 하늘빛 그대로, 밝은 종이에서는 짙은 쪽으로 옮겨 글자로 써도 읽히게(대비 4.8:1 이상) 맞춰요.
- 살짝 떠 있는 바탕은 `color-mix(in srgb, var(--sm-ink) 4~8%, var(--sm-paper))` 처럼 섞어서 만듭니다. 그래서 밝은 화면 · 어두운 화면 어디서든 같은 규칙으로 보여요.

## 글자

| 자리 | 글꼴 | 크기 · 굵기 |
|---|---|---|
| 화면 제목 | 고딕(`--sm-sans`) | 28px · 800, 자간 좁게 (폰 24px) |
| 교과 이름 | 고딕 | 18px · 750 (폰 17px) |
| 수업 이름 | 고딕 | 17px · 750 |
| 본문 · 수업 흐름 | 고딕 | 15~16px · 줄 간격 1.6~1.7 |
| 보조(학년 · 앱 이름 · 개수) | 고딕 | 13px · 흐린 글자 |
| 번호 · 계기판 숫자 | 고정폭(`--sm-mono`) | 13px(번호) · 20px(계기판) |

글꼴 파일은 바깥에서 받을 수 없어 기기에 있는 고딕 · 고정폭 글꼴을 차례로 씁니다. 꼭 같은 글꼴이 필요하면 woff2 파일을 `dist` 안에 넣으세요(파일 하나 2MB까지).

## 모양

- **모서리**: 거의 각지게 2px. 둥근 알약 모양은 쓰지 않아요.
- **머리 상자**: 옅은 모눈(24px 칸) 위에 제목을 올리고, 네 모서리에 글자색 꺾쇠(16px)를 붙여요. 오른쪽 위에는 궤도 그림을 옅게 깔아요.
- **계기판 숫자**: 수업 수 · 교과 수처럼 무엇의 수인지 이름을 붙이고, 숫자는 고정폭 글꼴 강조색으로 씁니다.
- **번호 표식**: 34×30, 강조색 테두리, 옅은 강조색 바탕, 고정폭 숫자 13px("06"). 교과 목차 순서 번호예요(01 공통 · 02 국어 …).
- **수업 카드**: 얇은 선 테두리, 살짝 떠 있는 바탕, 왼쪽 위에 강조색 꺾쇠(14px). 학년과 앱 이름은 작은 표지로, 앱 이름은 강조색에 조절 막대 그림을 붙여요.
- **단추**: 모서리 2px, 높이 44px 이상, 테두리 단추 · 글자색 바탕 단추 · 테두리 없는 그림 단추(44×44) 세 가지.
- **빈 자리**: 점선 테두리 상자에 작은 궤도 그림과 '아직 담은 수업이 없어요'를 적어요.

## 바닥 규칙(바꾸지 않아요)

- 쌩 흰색(#fff) 바탕을 쓰지 않습니다. 밝은 화면도 종이색이에요.
- 화면 기호는 SVG 로 그립니다(이모지 · 문자 기호 금지).
- 한글은 `word-break: keep-all`, 넘치는 글은 `overflow-wrap: break-word`. `anywhere` 는 글자를 한 글자씩 세로로 쌓이게 해서 쓰지 않아요.
- 긴 줄표 대신 쉼표 · 마침표 · 가운뎃점으로 씁니다.
- 누르는 자리는 44px 이상으로 둡니다.
- 밝은 화면과 어두운 화면 둘 다에서 읽히는지 연습용 도름스의 '색'을 바꿔 확인합니다.
